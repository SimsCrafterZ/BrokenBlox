# BrokenBlox
A brick-breaker game made with SmileBASIC.
# installation
manually:<br>
1-go to <a href="https://github.com/SimsCrafterZ/BrokenBlox/releases/">the releases page</a>
<br>
2-download the latest files TBROKENBLOX, BSPBLOX and BBGBLOX<br>
3-copy these files into a folder named BROKENBLOX anywhere on your 3DS SD card<br>
4-move this folder into the "root" of SmileBASIC using sbfm (SmileBASIC file manager), available here: https://github.com/nnn1590/lpp-3ds-sbfm or on Universal Updater<br>
5-go to SmileBASIC, launch BROKENBLOX and have fun!
